# useful-references
The provisioned urls can be urls to the Github repositories or individual files, and academic paperworks.
- If it is a Github repository, please (1) Open the repository page. (2) Click the green `<> Code` button. (3) Click `Download ZIP`.
![alt text](image.png)
- If it is an individual file of a Github repo, please (1) Go to the file page of the repo. (2) Click the `Download raw file` icon on the right side.
![alt text](image-1.png)
- If it is a PDF, please (1) Open the PDF viewer on the browser by clicking a button. (2) Click the `Download` icon on the PDF viewer.
![alt text](image-2.png)
